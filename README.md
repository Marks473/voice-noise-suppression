# Шумоподавление для голосовой связи в цехе

Сквозной проект курса «Обработка сигналов» (01.03.02, 4 курс). Кейс №8
(речевой интерфейс оператора) — прототип КСППР: от зашумлённой записи речи
до рекомендации ЛПР о состоянии голосового канала.

Полный план работы (10 этапов), легенда кейса и критерии готовности — в
[PLAN.md](PLAN.md).

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate        # Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
```

## Структура

```
src/            код обработки сигналов (по модулю на этап)
notebooks/      ноутбуки с демонстрациями по этапам
data/external/  сырые датасеты (локально, не в git)
data/samples/   маленькие демонстрационные аудиоклипы (в git)
data/processed/ сгенерированные смеси и результаты обработки (не в git)
results/        графики и метрики для отчёта
```
